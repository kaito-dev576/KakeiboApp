# 家計簿アプリ

## 概要
Pythonで作成したCLI（コマンドライン）の家計簿アプリです。

## 使用技術
- Python
- JSON

## 主な機能
- 収支の追加
- 一覧表示
- 合計表示
- 収支の編集
- 収支の削除
- JSONによるデータ保存・読み込み

## 学習したこと
- クラス
- オブジェクト指向
- 関数
- JSON操作
- CRUD
- リファクタリング

## 実行方法

```bash
python main.py
```
